# 灵犀 · 主动对话插件

> 作者：灵犀 | 仓库：[astrbot_plugin_Spark](https://github.com/gongzhudeng/astrbot_plugin_Spark) | 主页：[gongzhudeng](https://github.com/gongzhudeng)

> **插件名**：`astrbot_plugin_Spark`

灵犀让 AI 像真人一样主动找你聊天——在对话沉寂一段时间后自然地重新开口，或者在你们正聊着的时候概率性地追加一句话，营造更真实的对话体验。

灵感参考：[astrbot_plugin_Conversa v3.0.0](https://github.com/Luna-channel/astrbot_plugin_Conversa) (Luna-channel)

---

## 核心特性

### 两步式主动对话

主动回复不再靠句号约定拦截，而是拆分为两步：

1. **智能判断** — 用独立 LLM 判断当前是否适合主动开口（可配置专用供应商和人格）
2. **内容生成** — 判断通过后才生成回复内容（同样可独立配置供应商和人格）

两步可使用不同模型，实现"小模型判断 + 大模型生成"的成本优化。

### 沉寂问候

与用户最后一次聊天结束后，经过可配置的沉寂时间，AI 会主动发起问候。

- 触发时间由基准时间叠加统一时间变化策略计算
- 支持不偏移、双向随机、随机提前/延后、固定提前/延后和自定义随机区间
- 旧版“随机波动”配置继续按双向随机处理，并保留至少 1 分钟的保护
- 随机结果小于等于 0 时稍后重算；固定结果无效时结束本轮，等待用户下次聊天
- 支持多个提示词模板随机选择
- 用户可通过 `/灵犀 set after <小时>` 设置个人专属触发时间

### 对话热度系统

根据最近消息密度动态调整沉寂问候的触发间隔：

- **热度高**（近期密集聊天）→ 冷场后更快主动联系（最短 30 分钟）
- **热度低**（一直偶尔聊）→ 触发间隔保持较长（最长 1200 分钟）
- 使用指数衰减计算，平滑过渡
- 提示词模板支持 `{heat_level}` 占位符（值为"冷/温/热"）

### 私聊对话增强

AI 正常回复用户后，短时间内有概率主动追加消息，像真人聊天一样自然接话。

- 可配置触发概率、等待时间范围
- 用户在等待期间发新消息时自动取消

### 无限每日定时问候

支持添加无限数量的每日问候项，每项独立配置：

- 时间来源可选固定时间，或忙碌日程中的活动开始/结束边界
- 活动名称包含任一关键词即匹配；可选择全部或第 `1/2/3...` 次匹配
- 每个匹配活动独立触发，同一分钟的多个任务不会互相覆盖
- 支持单框时间变化语法，偏移可自然跨日；错过目标分钟不会补发
- 聊天冷却同时参考用户消息、普通 AI 回复和所有主动消息
- `ignore_dnd` 仅控制是否绕过免打扰与忙碌状态，不能绕过聊天冷却
- 支持多个提示词模板随机选择

### 忙碌时段免打扰

与 `astrbot_plugin_busy_schedule` 深度集成：

- 忙碌时段自动静默，不主动发消息
- 每日问候可选择是否忽略忙碌状态

### 其他特性

- **免打扰时段**：全局或用户专属，支持跨天（如 23:00-07:00）
- **自动退订 & 重新激活**：不活跃用户自动退订，再次发消息自动恢复
- **Agent 订阅**：支持手动 / 自动 / AI 工具三种订阅方式
- **人格继承**：完整使用 AstrBot 人格系统，支持 `_special: select_persona` 下拉选择

## 安装

在 AstrBot WebUI → 插件市场中搜索 **灵犀** 安装，或手动将插件放入：

```
AstrBot/data/plugins/astrbot_plugin_Spark/
```

重启 AstrBot 后在 WebUI 中启用即可。

---

## 快速上手

1. **订阅会话**

   在聊天中发送：
   ```
   /灵犀 watch
   ```
   或在 WebUI 插件配置的「订阅用户列表」中添加会话 ID。

2. **等待触发**

   默认沉寂 1200 分钟（20 小时）后触发问候。可以调短试试效果：
   ```
   /灵犀 set after 1
   ```
   （设置为 1 小时后触发）

3. **（可选）设置免打扰**
   ```
   /灵犀 set quiet 23:00-07:00
   ```

## 指令一览

| 指令 | 说明 |
|---|---|
| `/灵犀 help` | 显示帮助 |
| `/灵犀 debug` | 显示调试信息 |
| `/灵犀 on` / `off` | （管理员）启用/停用插件 |
| `/灵犀 watch` / `unwatch` | 订阅/退订当前会话 |
| `/灵犀 set after <小时>` | 设置个人沉寂问候时间（最低 0.5） |
| `/灵犀 set quiet <HH:MM-HH:MM>` | 设置个人免打扰时段 |
| `/灵犀 set quiet <...> global` | （管理员）设置全局免打扰 |
| `/灵犀 remind add <HH:MM> <内容>` | 添加每日提醒 |
| `/灵犀 remind add <YYYY-MM-DD HH:MM> <内容>` | 添加一次性提醒 |
| `/灵犀 remind list` | 查看提醒列表 |
| `/灵犀 remind del <序号>` | 删除提醒 |

## 配置说明

所有配置在 AstrBot WebUI → 插件配置中修改。

### 基础设置

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 订阅方式 | `manual` | `auto` / `manual` / `agent` |
| 免打扰时段 | 空 | 格式 `HH:MM-HH:MM`，支持跨天 |
| 自动退订天数 | 3 | 用户连续无回复天数后自动退订，0 禁用 |
| 回复间隔（秒） | 20 | 多个主动回复之间的间隔 |

### 主动对话设置

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 启用智能判断 | 是 | 是否用 LLM 判断是否适合主动开口 |
| 判断用人格 | 空 | 下拉选择判断步骤使用的人格 |
| 生成用人格 | 空 | 下拉选择生成步骤使用的人格（空=主人格） |

### 沉寂问候

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 启用 | 开 | 总开关 |
| 沉寂基准时间（分钟） | 1200 | 最后一次聊天后多久触发 |
| 随机浮动（分钟） | `30` | 单框填写：`0` 不变化；`5` 前后随机；`+5` 固定延后；`-5` 固定提前；`-5~+5` 等区间表示随机范围。旧整数配置会在插件加载时自动迁移 |
| 聊天冷却（分钟） | 10 | 延时任务到点后，若距离用户消息、普通 AI 回复或任意主动消息不足此时间，则顺延到冷却结束；0 关闭 |
| 问候提示词模板 | 内置 1 个 | 综合处理话题延续、问候、近况、照片和语音 |

### 每日定时问候

支持无限添加问候项，每项包含：

| 字段 | 说明 |
|---|---|
| `enable` | 是否启用 |
| `trigger_source` | `固定时间` 使用固定时间；`日程活动` 使用忙碌日程活动边界 |
| `time` | 固定时间，格式 `HH:MM` |
| `activity_keywords` | 标签列表；活动名称包含任一关键词即匹配 |
| `activity_boundary` | 使用 `活动开始` 或 `活动结束` 时间 |
| `activity_occurrences` | 留空表示全部；`123` 与 `1,2,3` 都表示第 1/2/3 次，越界序号忽略 |
| `prompt` | 问候语（支持占位符） |
| `cooldown_minutes` | 聊天冷却；未满足时直接跳过，不调用判断或生成模型 |
| `ignore_dnd` | 是否忽略免打扰和忙碌状态；无论取值如何都必须满足聊天冷却 |
| `jitter_minutes` | 单框时间变化：`0` 不变化，`5` 前后随机，`+5`/`-5` 固定延后/提前，带 `~` 的值表示随机区间 |

活动模式依赖 `astrbot_plugin_busy_schedule` 提供结构化日程。普通活动缺少结束时间属于异常数据；最后一项开放睡眠可以直接使用开始时间，其结束时间只有在下一日程周期首个普通活动可用时才能解析。选择结束边界但无法解析时，该次匹配会被跳过并记录日志，不会猜测或回退到其他时间。

时间变化允许自然跨日。每日任务只在目标分钟触发，插件启动晚于目标分钟或门禁未通过时不会补发。随机偏移使用稳定任务种子，插件重启不会改变当次目标时间。

### 私聊对话增强

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 启用 | 关 | 总开关 |
| 触发概率（%） | 20 | 每次 AI 回复后的触发概率 |
| 最短/最长等待（秒） | 30 / 600 | 触发后的等待时间范围 |

### 提示词占位符

所有提示词模板支持以下占位符：

| 占位符 | 含义 | 来源 |
|---|---|---|
| `{now}` | 当前时间 | Spark 内置 |
| `{time_since_last_chat}` | 距离上次聊天过了多久 | Spark 内置 |
| `{last_user}` | 用户最后一条消息 | Spark 内置 |
| `{last_ai}` | AI 最后一条回复 | Spark 内置 |
| `{umo}` | 会话 ID | Spark 内置 |

| `{heat_level}` | 当前对话热度（冷/温/热） | Spark 内置 |

> v1.4.0 起，节律插件（`astrbot_plugin_time_period_prompt`）、记忆召回（`astrbot_plugin_livingmemory`）、知识库等内容均通过 `OnLLMRequestEvent` 钩子自动注入，无需在提示词模板中手动添加占位符。如你之前配置了 `{time_period_prompt}`，请手动删除，否则会导致节律内容重复注入。

### 灵犀AI忙碌时段管理插件集成

本插件支持 [astrbot_plugin_busy_schedule](https://github.com/gongzhudeng/astrbot_plugin_busy_schedule)（灵犀AI忙碌时段管理）插件的提示词自动注入。

安装了忙碌时段管理插件后，本插件的主动对话会自动注入以下内容到 AI 的 system_prompt 中：
- 今日穿搭
- 今日日程安排
- 当前活动
- 下一个活动
- 自定义注入提示词

无需任何配置，安装即生效。这使得主动对话的 system_prompt 与正常对话保持一致，共享 KV Cache，提高缓存命中率，降低 API 调用成本。

| 文件 | 内容 |
|---|---|

## 故障排查

**没有收到主动消息？**
- `/灵犀 debug` 确认订阅状态和插件是否启用
- 检查是否处于免打扰时段或忙碌时段
- 确认沉寂时间是否已到（默认 1200 分钟 = 20 小时）

**消息内容不理想？**
- 在 WebUI 中修改提示词模板
- 尝试切换生成用人格
