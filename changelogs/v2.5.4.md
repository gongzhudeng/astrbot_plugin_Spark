# v2.5.4

## Fixes

- Restore the Agent Pipeline on AstrBot 4.27.3, where `build_main_agent_config` is no longer exported by `astrbot.core.astr_main_agent`.
- Add a compatibility adapter that maps current AstrBot provider, context, safety, file extraction, sandbox, proactive-tool, subagent, and timezone settings into `MainAgentBuildConfig`.
- Continue using the framework-native config builder when it is available on older compatible AstrBot versions.
