# v1.6.7

## Fixes

- Stabilize proactive reply context by explicitly loading recent real conversation rounds with `gen_history_rounds` while keeping Agent Pipeline hooks active.
- Add configurable proactive fact envelope modes. The default `minimal` mode only marks the turn as AI-initiated, while `full` keeps the realtime facts envelope for cases where older memory or knowledge base results need stronger demotion.
- Clean proactive retrieval queries by filtering commands, proactive prompt markers, and system residue, then limiting query length before memory and knowledge base retrieval.
- Split proactive retrieval query from the final generation prompt so memory and knowledge base retrieval use recent real chat instead of the proactive trigger instruction.
- Skip delayed conversation enhancement when any newer chat appears during the delay or when the latest chat is still inside the cooldown window.
- Restore the `gen_history_rounds` configuration description as an active generation context control.

## Added

- Add `heat_window_minutes` with compatibility for the old `heat_window_hours` setting.
- Add `heat_messages_for_full_score` to make conversation heat harder or easier to reach full score.
- Add `enhancement_cooldown_minutes` to avoid follow-up messages immediately after recent chat.
